# 🫀 Overview

**Heart Disease Detection using Machine Learning** is an AI-powered healthcare prediction project that estimates the likelihood of heart disease based on a patient's medical information.

Using Machine Learning techniques, the model analyzes various health parameters and predicts the patient's risk level while providing easy-to-understand health recommendations.

This project demonstrates the practical application of Artificial Intelligence and Machine Learning in the healthcare domain.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/Heart-Disease-Detection-ML.git
```

Move to the project directory

```bash
cd Heart-Disease-Detection-ML
```

Install the required libraries

```bash
pip install -r requirements.txt
```

# ▶️ How to Run

1. Open the notebook in **Google Colab**.
2. Upload the dataset (if required).
3. Run all notebook cells sequentially.
4. Enter the patient's medical details.
5. View the prediction, risk level, and recommendations.
