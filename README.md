##Heart Disease Detection using Machine Learning

Project Description

An AI-based system that predicts the risk of heart disease using patient health parameters. The model analyzes medical inputs and provides a risk level along with health recommendations.

Features

* User-friendly input system for patient data
* Machine learning-based prediction
* Risk classification (Low / Mild / Moderate / High)
* Health indicator levels (Green / Yellow / Red)
* Preventive recommendations based on results

Technologies Used

* Python 
* NumPy
* Pandas
* Matplotlib / Seaborn
* Scikit-learn
* Google Colab

Dataset Information

The dataset includes important medical attributes such as:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol Level
* Blood Sugar
* ECG Results
* Maximum Heart Rate
* Exercise-Induced Angina
* And more...

How to Run the Project

1. Open the notebook in Google Colab
2. Run all cells step by step
3. Enter patient details when prompted
4. View prediction results and recommendations
